# E004 — global low-rank pair interactions

> Historical Track A: knowledge-free NNUE versus material-bootstrapped BRN-3.
> Preserved as architectural-control evidence by the 2026-10-05 fairness amendment;
> rejection statements here do not apply to the new bootstrap-parity Track B.

Registered 2026-10-05 after E003 strength results: local3 0/96, local5 1/96,
zero-head 3 draws / 45 losses. Local nonlinear structure, despite inexpensive
updates, has not supplied the missing initial strength. Long-range interactions
remain a distinct architecture hypothesis that local neighborhoods do not test.

Maintain first and second moments of 32-dimensional learned piece-square
embeddings, independently for both relative perspectives. The identity
`(sum e)^2 - sum(e^2) = sum_{i != j} e_i e_j` supplies low-rank relationships
between all distinct pieces without enumerating every pair. Apply learned linear
and quadratic readout coefficients and an antisymmetric perspective projection.
Only changed pieces update the two sums; per-ply state is 128 doubles plus a count.
This is an incremental polynomial neural representation, not BRN-3's relational
tables or per-entity nonlinear recomputation.

Two arms: `global-linear` disables only the quadratic readout, and `global-pair`
retains it. Both receive identical embeddings and readout draws for a seed.
Embeddings use symmetric uniform +/-1; readout weights symmetric uniform
 +/-1/sqrt(32). Divide linear and pair terms by sqrt(n) and sqrt(n*(n-1))
respectively (clamped denominator minimum 1), controlling combinatorial scale
from factual piece count. No value sign, material ranking or chess target enters
initialization. Final tanh and normal NNUE score mapping remain.
Parameters: linear 24,608, pair 24,640. This explores a different representation,
nonlinearity, width and initialization regime, not just another HalfKP scale.

Stage1: two-moment full-refresh equivalence, chained/special moves, colour and
perspective checks, six-seed warmed costs/topology. Stage2 if correct: fixed six
seeds/eight paired openings/depth3/cap2048 against unchanged BRN-3. Preserve the
linear ablation and all seeds, not just a positive material preference by chance.
No training or promotion without strength and cost evidence.

Eleven focused tests now pass, including the new global chained/full-refresh
oracle and confirmation opening independence. Six-seed audit completed: global
linear median transition+readout **125 ns**, full refresh **803 ns**; pair **184
ns**, full refresh **857 ns**. Pair max raw error 3.331e-16, linear error zero.
Quiet correlation .932..962 (linear), .906..946 (pair). This is a meaningful
incremental advantage and a different initialization scale; cheap evaluation
alone is not yet strength evidence. Both six-seed/eight-pair match arms running
in e004-matches, concurrently with the fixed-depth E005 confirmation. Their wall
times are not standalone throughput benchmarks.

Stage2 results: linear **2 wins / 0 draws / 93 losses / 1 cap**, pair **3 wins /
0 draws / 93 losses**, each 96 games. Pair's small score difference is not
evidence of a strength improvement. Reject both as fixed-depth contenders while
retaining the very cheap pair model for the predeclared equal-time test E006.
