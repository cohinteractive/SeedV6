# E005 — independent negative-result confirmation

> Historical Track A: knowledge-free NNUE versus material-bootstrapped BRN-3.
> Preserved as architectural-control evidence by the 2026-10-05 fairness amendment;
> rejection statements here do not apply to the new bootstrap-parity Track B.

Registered 2026-10-05 **before confirmation outcomes**, during E004 cost audit.
The common six-seed/eight-opening screens show very large deficits, but reused
openings and small initialization count limit population uncertainty estimates.
Use genuinely new initialization and opening blocks before a terminal inference.

Preselected representative mechanisms, without selecting lucky seeds or wins:
`baseline,odd,smooth,counts,local3,local5,global-pair,zero-head`.
These cover the original reference, consistent readout, geometric sharing, exact
counts, two local receptive fields, global low-rank pair interactions and zero
initial readout. Precision-only, mirrored smooth and piece-square-only arms remain
rejected screening results, not silently promoted. Global linear is E004's
mechanism ablation rather than a full new contender.

32 new independent initialization seeds are generated **once** with Python's
Random(2026100504), getrandbits(63), and written to confirmation-seeds.csv before
running games. Each initialization receives two distinct paired openings (four
games), seed 2026100503, indices `2*seedOrdinal` and `2*seedOrdinal+1`. The same
block is used across all eight architectures. No opening or seed filtering.
128 games per architecture, 1,024 total. Required depth3, cap2048, other search
controls unchanged. No adaptive stopping from intermediate scores. This run is
authorized research, not an application promotion or trained-strength claim.

Analysis unit: each independent initialization/opening block's mean score,
bounded in [0,1]. For every architecture, report observed W/D/L and cap counts,
seed means and the conservative upper bound treating every unscored game as a
candidate win. The one-sided Hoeffding upper bound is
`mean(worst-case block scores) + sqrt(log(8/.05)/(2*32))`, clipped to one.
Bonferroni adjustment over the eight preselected architectures supplies a
simultaneous 95% bound under the independent-block sampling assumption. Radius
is approximately .282; this deliberately conservative experiment can rule out
.45 only for large deficits. If the bound reaches .45, gather more evidence or
continue with that contender rather than forcing a negative conclusion.
For zero-head the initialization does not change the function, but opening blocks
still vary independently; there is no claim of neural seed variance.

This can establish failure of the **tested mechanisms**, not a theorem excluding
every possible NNUE. Any terminal assessment must additionally explain remaining
plausible directions and fairness boundaries without equating difficulty with
impossibility. Trained parity remains unknown unless actual training is run.
