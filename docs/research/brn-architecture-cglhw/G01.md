# G01: learned logic gates over spatial bitboards

Current disposition: further mainline circuit expansion is deferred after Z01. Learned gates improve raw prediction, but direct playing value over fixed gates is inconclusive; pairs search faster and have the stronger practical case. Historical steps below are retained.

Initial recorded status: serious one-layer training+96games and matched fixed-gate control complete;
both one-layer variants retained for fresh replication;gate-choice benefit unproven.

[Petersen et al.](https://arxiv.org/html/2210.08277v1) learn a softmax distribution
over16binary truth functions at fixed random connections,then use the modal gate
at inference. Their training relaxation uses real-valued Boolean polynomials.
They pack independent examples into machine words. This experiment instead packs
the64spatial squares of ONE chess position into a bitboard and shares spatial gate
operators. Their classification throughput cannot be transferred to this setting.

## Frozen first adaptation

Use13raw canonical bitboards(empty plus12owner/type categories),separately for the
two color/rank perspectives. No attack,mobility,king-safety or handcrafted score
inputs. Each layer has32gates. Each gate selects two fixed pseudo-random source
maps and integer geometric shifts;first-layer sources are raw maps with dx/dy
in[-2,2],later sources are previous-layer gates with shifts in[-1,1]. Outside-board
cells are zero and file wrap is forbidden. Store exact topology in checkpoints;
use independent RNG streams for topology and standard-normal initial gate logits.
One-layer and two-layer variants share the first-layer topology/logit prefix.

For each gate,16logits define a temperature1softmax. Its soft output is the convex
mixture of all Boolean truth functions,implemented as c0+cA*a+cB*b+cAB*a*b.
Accumulate gradients for these four coefficients over squares/perspectives,then
differentiate softmax once per batch. This is an optimization of the same mixture,
not a substitute hand-selected set of Boolean features. Test all16truth functions.

Expose every layer's outputs to the head,providing a direct first-layer path.
For each gate/perspective,count/sum activation within each of8rank and8file masks.
Those masks encode raw geometry only. Divide features by sqrt(32*16),learn separate
mover/opponent scalar weights,and add scalar bias plus the fixed material prior.
All head weights/bias start zero for exact material Gen0. One-layer trainable count
1537;two-layer3073. Inference stores hard operator IDs,topology and float head,
not soft gate logits. Model size and CPU latency must be measured,not estimated
from tiny parameter count. No dense hidden layer or imported chess heuristic.

Hard inference uses bitwise Boolean gates,masked shifts and Long.bitCount;
training uses the differentiable relaxation. The soft/hard discrepancy is a primary
risk:report both qualities,modal probability,constant/unary gate counts and every
failed hardening attempt. Never report soft prediction as actual deployed quality.
