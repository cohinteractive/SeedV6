# C02: prospective compilation of equivalent pair-table terms

Status: justified follow-up hypothesis, not implemented or measured. Recorded
2026-10-06 after the complete Z01 screen and learning/practical-control gate.

C01 pair tables are the principal practical candidate, but their learned engine
scores 39.84375% against cheap material and their own-Gen0 interval still includes
.5. Their native child update is about .45 microseconds versus material's .044.
The current pair model deliberately inherits 327 triple-template anchors and
ignores each third cell. Some remaining two-square terms repeat, including
reversed addresses. Inference also evaluates both canonical perspectives and
both roles. Those choices preserve the original causal pair/triple comparison;
they need not be the cheapest implementation of the learned pair function.

Hypothesis: compile all role/perspective terms into tables over unique unordered
physical square pairs, with a scalar sum for each side to move. Map ownership
categories and rank reflection exactly when compiling. Combine duplicate terms
in binary64 and retain the original normalization and bias. Inference then updates
only affected unique pairs and two sums. Do not quantize or retrain initially.
This is an inference-equivalent descendant, not a claim of improved expressivity,
new supervision or architectural originality. It isolates whether redundant
evaluation cost obscures the already-trained pair function's practical value.

Keep the original trainer, codec, models and workspace available for direct
controls. A separate research loader identity must distinguish the compiled
runtime from the original even if their source model bytes are identical. Bind
metadata as well as model bytes in subsequent frozen plans. No production code,
model stores, selected default or training recipe may change for this experiment.

Before any cost/strength allocation: independent forward comparison to the
original model, random/legal/special/undo/STM transitions, information and color
invariants, immutability, finite/bounds checks and actual-model validation-board
parity. Require maximum pawn error <=1e-8 on the tested actual models, record every
integer-score difference, and investigate any difference before calling the
function preserved. Compilation changes floating-point summation order; exact
universal bitwise equivalence is not assumed from algebra.

After correctness passes, common warmed transitions and 128 depth4 roots for
both original and compiled versions of the same two frozen models, including
Gen0 costs and full process/model/workspace memory. Accept additional paired
games only if there is a material measured inference/search gain. Use the same
models/gains and fresh prospectively audited openings. Learning and cheap-prior
controls remain distinct. No zero-weight shortcut for Gen0. No new training or
large game campaign is admitted by this hypothesis record alone.

Prospective cost allocation rule, recorded before any C02 measurement: supplement
the native-loader probes with original/compiled child updates in the same JVM,
using the common request stream, 64 warmup pass pairs and ten timed pass pairs
with alternating evaluator order. All raw passes and special-move groups remain
visible. Admit a small playing comparison only if both trained A/B models reduce
median child cost by at least 15%, all parity/completion checks pass, and the sum
of their two compiled depth4 search times is below the original sum. Record Gen0
costs separately; they cannot substitute for the trained-model criterion. If the
two timing methods materially disagree or the decision lies within observed pass
variation, permit one predeclared repeat of the same complete cost allocation,
retain both attempts, and defer if the combined evidence is still inconclusive.
This is an allocation threshold, not a statistical strength or final adoption rule.
Bind actual paths, weights, metadata, datasets, commands and limits in the cost
plan before execution. The new same-JVM helper is currently an uncompiled draft.

Implementation must wait until the active Z01 longer-budget queue, its historical
reference bridge and the nested-data training study are complete; their current
source/compiled manifests are frozen. Each subsequently selected long-budget model
also needs its own compilation/parity evidence before a compiled engine uses it;
parity on an earlier exposure-selected checkpoint does not cover different weights.
This record adds a supported hypothesis
to the shared frontier, not an excuse to overwrite prior evidence or postpone
the programme indefinitely. If compilation fails its parity/cost gate, preserve
that evidence and defer it.
