Question:can inexpensive learned univariate functions of the192BRN pooled states
improve on B01's linear readout while preserving much of its speed? This is a
single additive layer of learned edge functions after the unchanged relational
encoder,not a claim to reproduce every architecture in the
[KAN paper](https://arxiv.org/abs/2404.19756). It differs from C01's categorical
tuple addressing:inputs here are continuous learned pooled states.

Keep the BRN encoder,initialization,fixed material,objective,shuffle,batch and
quarter-residual search. Replace the global readout by `R=b+sum_j f_j(x_j)`.
Each nonnegative pooled coordinate owns16learned knot parameters q1..q16 at
x=.5,1,...,8,with q0=0 fixed. At knot k,the function value is`.5*q_k`.
Interpolate linearly between knots and extrapolate with the last segment above8;
there is no hard clipping. The .5scale makes the first segment exactly q1*x,
preserving the linear readout's parameter scale for small activations. Setting
q_k=k*w_j recovers the exact linear function at every x,including the tail.
Learned functions need not be monotone. A separate scalar bias remains.

Inference2365441/training2624641 parameters;192table addresses/interpolations
replace a dense hidden layer. Shared relative embedding parameters still fold
into the BRN absolute relation table. Use independent verification-only codecs
and worker-local R01-style inference;no production identity or selector changes.
Record the fraction of pooled coordinates above8 and maximum observed activation,
so range/conditioning problems cannot be hidden by an assumed grid.

Feasibility gates:independent interpolation/tail checks,exact linear submodel,
finite gradients away from knots,documented one-sided derivative at knots,tiny
fit,information/color symmetry,CRC/exact continuation,immutable folded model and
incremental legal/special-move parity. No real training before these pass.

Initial two runs:16384x4,seeds71/97,masked Adam.003,batch128,data02 and first4096
validation selection,300s/2GiB. B01 linear is the causal architecture control;
full BRN3 remains the reference. A second grid/rate recipe needs an observed
coverage or conditioning reason. Admit131072x8 for>=2% quality gain or credible
cost/strength opportunity. No sealed labels,automatic mixture/hybrid or adoption.
