## Primary external research (consulted2026-10-06)

These motivate hypotheses; their reported tasks/hardware do not prove chess results.
* [Blondel et al., polynomial networks/FMs](https://proceedings.mlr.press/v48/blondel16.html):
  low-rank tensor view motivates explicit relation-product readout and rank ablation.
* [Higher-order FMs](https://arxiv.org/abs/1607.07195): efficient controlled degree
  motivates a later degree3 test; do not enumerate all relation triples.
* [KAN](https://arxiv.org/abs/2404.19756) and [FastKAN](https://arxiv.org/abs/2405.06721):
  learned edge functions motivate a piecewise-linear/LUT experiment. Spline/RBF
  substitution is not automatically faster than Java dense arithmetic.
* [Differentiable weightless networks](https://arxiv.org/html/2410.11112v5): learned
  small LUT compositions motivate C01. Hardware-oriented gains require new CPU
  measurements; table/addressing cost and training approximations remain hypotheses.
* [Differentiable logic gates](https://arxiv.org/abs/2210.08277): relaxed training and
  hard logic inference motivate G01; quantify discretization error and native Java
  bitwise execution before admitting larger budgets.
* [MPNN framework](https://arxiv.org/abs/1704.01212): actual state-dependent propagation
  differs from static relation lookup; useful chess accuracy/latency remains unproved.
* [Giraffe](https://arxiv.org/abs/1509.01549): learned evaluation within search is a
  relevant precedent, not a directly comparable modern SeedV6 strength baseline.
