## Changed hypothesis

B01's linear readout removes the dense hidden layer and shows a cost/play lead.
Test whether that saved work can pay for one contextual state update. This changes
the previously tested cost/representation combination;it does not claim the mean
message itself is novel. Keep the width8 absolute/shared BRN encoder,typed pools,
linear scalar readout,fixed material and existing supervision. For first-layer
nonnegative local states h_i,define:

`h2_i = ReLU(h_i + A*h_i + B*mean_{j!=i}(h_j) + c)`.

Compare CONTEXT against matched SELF(`B`absent) and B01 LINEAR(no second layer).
A,B,c start zero:the second layer initially equals the first. All readout weights
start zero,so every Gen0 is material-only. No rule-state or handcrafted feature.
The historical context-plus-MLP experiment used random context initialization;
this identity initialization is also a recipe change. Comparisons against that
old result do not isolate the head alone. New SELF/CONTEXT runs share this recipe.
Inference factors the mean broadcast as `B*sum(h)/(n-1)+(A-B/(n-1))*h_i`,with the
same max(1,n-1) convention,so it needs one8x8 transform per piece after a shared
broadcast. This saves work versus evaluating self and other terms separately.

SELF adds72(inference2362633/training2621833). Measure cost;an operation count is
not a speed result. Use independent verification codecs,folded float models and
the R01 raw-relation cache. Keep earlier successor artifacts/source unchanged.

Feasibility before corpus training:independent directed other-piece sum,exact
linear identity when second-layer parameters are zero,all-block finite gradients
including cross-piece derivatives,matched SELF ablation,tiny fit,symmetry/input
isolation,exact continuation/CRC and incremental special/legal parity.
