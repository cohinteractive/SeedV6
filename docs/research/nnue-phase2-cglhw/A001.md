# A001 — independent-seed training factors

Prospective protocol, 2026-11-14, before new training. Primary comparator WDL25.
Same conventional256/8-head architecture and unmodified inference. Fixed new seed
2026111501, batch4096×1024, endpoint64 (268,435,456 exposures); LR.001, gamma.5.
Five planned recipes: broad/WDL.25/drop32 reproduction; broad/WDL0/drop32;
broad/WDL.50/drop32; narrow/WDL.25/drop32; broad/WDL.25/drop128. This is a
controlled star design, not a full factorial: interactions are unestimated.

The first reproduction runs1..4, export/integer+GPU parity and diagnostic checks,
then5..64 only after passing. Other controls may be pruned for a verified validity
or resource reason, never an unreported unfavorable loss. Freeze each actual recipe
in its JSON before launch. Different targets' training losses are incomparable.
All models use the common frozen6753-position diagnostic; it is not game-independent.

Record initializer equality for same-seed controls, effective global LR, data
stream offsets and exact optimizer continuations. Reproduction means statistical
behavior under an independent seed, not bit-identical GPU weights. No causal Elo
claim from prediction loss. Use fixed paired screens against WDL25 after correctness;
report within-screen controls as exploratory, not independent confirmation.

Budget: <=5×64 superbatches, native-process wall<=3600s, supervisor wall<=7200s.
Each4-superbatch pilot precedes continuation for novel recipe/geometry. Nonfinite
loss, incorrect export/parity, unexpected recipe/stream mutation, resource conflict
or owner HOLD stops affected work. A budget overrun triggers a documented new
economics decision, not automatic extension or research completion.
