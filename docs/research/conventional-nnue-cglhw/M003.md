# M003 - bounded Java Vector API feasibility

Prospective2026-10-22, while E007 trains independently. Current256-unit scalar
incremental/head cost is around1.8us and much higher than the frozen Gen32 primitive.
M002's integer-head change had no benefit and remains rejected. Before widening the
conventional hidden layer, measure explicit SIMD on existing hardware with unchanged
weights/arithmetic. This is a separate local prototype, not application adoption.

Use installed JDK21 jdk.incubator.vector with preferred species. Clamp int inputs,
square and multiply each signed-short weight in int (each individual product fits),
then widen each product to long before any addition/reduction. Keep the long scalar
reference, exact divisions and score clamp. Preexpand only tiny output weights to
int. Do not change checkpoint bytes. Check real259 probe scores against existing
incremental/full inference, then10000 adversarial raw dot products including full
signed-short extremes before score saturation. Warm both kernels and alternate
five timed samples on identical inputs; observe hot allocation. Head-only results
cannot establish engine NPS/Elo or integrated benefit. Preserve negative outcomes.
