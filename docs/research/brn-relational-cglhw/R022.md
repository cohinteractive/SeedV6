# R022 square-field to piece composition

Prospective after R021. Existing R017 ALL computes nonlinear messages at each
controlled square,but sums those square readouts independently except for a shared
king context. R019 mixes channels within one square;it cannot directly compose
several squares controlled by one piece. R020/R021 representation/optimizer
controls did not improve the same fixed learning budget. Test a new relational
path rather than extending those failed tuning recipes.

Retain R017 ALL field equations and shared tensors. For each piece q and dimension d,
aggregate its attacked/control squares t:

b[q,d] = sum_t U[type(q), displacement(q,t),d] * softsign(z[t,d]) / sqrt(outdegree(q))

Add sum_q,d V[piece-square(q),d] * softsign(b[q,d]) /8 to the neural logit.
All tensors and the original field/king-context paths train jointly. This is
learned composition of attacker-to-square relations followed by square-to-query
relations and nonlinear query readout. It can express joint effects among squares
controlled by the same piece;capacity is not chess correctness. No NNUE or Pair-2
inference backbone. Added U has2700*8 weights,V768*8,total68521 parameters.
V initializes zero,U Gaussian .1;all shared parameters initialize exactly as R017.
A disabled second pass must reproduce R017 updates exactly. Serial full recompute;
no incremental/search integration or architectural success is implied.
