# R009 king-conditioned direct pair energy

Prospective after R008, before implementation outcomes or training. R008 found
nonlocal mixed responses in63/64 CP64 quartets,median absolute23.5cp without a
king-context change and34cp with one; Pair-2 is structurally zero. These responses
need not be correct or strength-producing. A cheap first intervention tests
explicit king conditioning rather than assuming more local-pair exposure suffices.

Freeze each seed's R002 epoch24 Pair-2 model as a relational starting function.
Fit a new additive table of **direct pair energies**, either SHARED or KING:
`logit = frozenPairPawns/4 + (bias + NORM*sum D[role,bucket,template,state])/16`.
SHARED has one bucket; KING has10 relative-king buckets from the verified CP64
geometry, without horizontal mirroring of pair features. Each role uses its own
perspective king; bucket is independent of STM color. A king relocation can
change a remote relation's energy. No learned hidden accumulator, dense NNUE head,
teacher at inference or NNUE residual is used. This is a standalone relational
function consisting entirely of material and direct/context-conditioned pair
energies. Reusing a king partition is not itself an architectural originality claim.

The fixed common relational base removes relearning as a confound. SHARED controls
for ordinary extra fitting; KING adds1,105,261 parameters versus110,527 in SHARED.
This is not parameter-matched. The base is unchanged during this screen; joint
adaptation/regularization remain separate hypotheses. Both have zero new weights,
fresh masked Adam(.01,.9,.999,epsilon1e-8),bias correction,batch128,MSE in logit400
probability space,seed+epoch shuffle. No distillation after R007's failed gate.
Use the same nested131072 original-target training rows and4096 development
validation rows,8 epochs,two seeds71/97,seed-matched frozen bases.

Prior programmes tested softmax pair experts,quadratic/cubic heads and context
propagation under different objectives. This is a specific new direct-table
king-conditioning test,not a claim that conditional relational work is new.
It does not reopen suspended W9 or negate its evidence.

Before training verify full formula and color symmetry,special boards,gradient,
zero-delta equality,nonlocal response with selected weights,finite behavior,
checksum and exact optimizer continuation. Full inference only initially;
incremental context-switch maintenance is unimplemented and must be verified
before playing. Require full inference<10us in the bounded cost screen.

Advance only if KING beats its matched SHARED validation MSE by>=2% in both seeds
at the fixed epoch8 endpoint,and does not worsen its own frozen base validation

Loss is admission evidence only,not strength. No final data is consumed.

Each arm: one logical CPU,512MiB heap,BelowNormal,no GPU,expected30–90s,max300s;
