# R056 factorized learned relational message composition

Prospective after R055's matched neural modulation gains fail both-seed gates.
Retain all checkpoints and useful ablation findings;no more epochs/rates/games.
R051-R053 also exposed practical costs of materializing many pair transformations.
Investigate a different relational parameterization with an algebraically cheap
global computation,not another categorical cache optimization.

Use learned piece/square source keys K[j,r],target queries T[i,r],and source
content E[j,d],rank4,width8. Relation w[j,i]=sum(r)K[j,r]T[i,r]/sqrt4.
First h[i,d]=softsign(sum(j!=i)w[j,i]E[j,d]/sqrt(n-1)). Read out per-piece h
using Q. TWO mode mixes nonlinear source states m[j]=h[j]+M h[j]/sqrt8,then
applies the SAME learned relational operator to m,softsign and per-piece V readout.
ONE mode omits that second path. Retain material and learned unary terms;no NNUE
inference backbone. Relations are signed learned weights,not normalized attention
probabilities;state-dependent neural composition remains central.

Compute P[r,d]=sum(j)K[j,r]E[j,d],then a[i,d]=[sum(r)T[i,r]P[r,d]
-sum(r)T[i,r]K[i,r]E[i,d]]/sqrt(4*(n-1));likewise for second-pass m.
The subtraction excludes self-edges exactly in algebra. Efficient forward and
backward pool contractions avoid quadratic pair loops;independent test oracle
must explicitly enumerate j!=i. Keys/queries are reused in BOTH passes,so their
gradients include both paths. No blocker feature or hand-coded attack edge is
assumed;this loss of geometric inductive bias is an explicit risk to test.

Architectural challenge:the first pooled tensor alone resembles an accumulator.
The evaluator must retain per-occupied-piece query-dependent nonlinear states,
self-edge exclusion and a second relational composition/readout;collapsing it
to a global conventional NNUE head would not satisfy this hypothesis. No claim
of world-first novelty,universal expressiveness or theorem-level separation from
all neural architectures. The rank constraint may discard crucial interactions.
