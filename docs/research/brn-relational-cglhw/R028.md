# R028 contextual all-piece neural messages

Prospective after R027. Primary hypothesis: passing already contextualized piece
states across learned nonlocal relations can improve CP64 prediction beyond one
layer of static source embeddings. This is not another Pair-2 intervention.

## Prior evidence and challenge

Actual MessageRelationCandidate uses all ordered piece pairs despite historical
"local" wording:typed-displacement vector additions,one tanh per piece,global
shared head,dual antisymmetric perspectives. The programme ledger records8k x4,

not test contextual second-pass messages,modern CP64 targets or1M examples.
PooledRelationCandidate aggregates factorized static pair products before an MLP;
repackaging that as a new NNUE-like relational input is not the objective.
R011's local wedge lacks support on38/64 remote contrasts. R012 king-anchor
messages provide global paths but compress through only two8D anchors;R013's
coverage improves training without clearing the architectural gate. R022 provides
useful square-to-piece composition,but small loss gains and poor R025 play.
R023 width growth and R027 scaling did not close the gap. None establishes that
all graph architectures fail,or that CP64's structural responses are correct.

New model has a nonlinear context state at EVERY piece,with learned geometry
transformations on both passes. Unlike the historical one-layer model,second
messages depend on the source's other relationships. Unlike R022,communication
is not restricted to occupied attacks/controlled squares or two global anchors.
All-pair geometry also omits explicit blocking/attacks;that inductive-bias and
cost limitation must be reported. No lookup-only conditioning or NNUE backbone.
