# R031 bounded neural warm-start step-size diagnosis

Prospective after R030. Both tested neural families remain far behind CP64 in
small fixed-node diagnostics;better old-development loss did not reliably improve
play. Do not extend tournaments or infer architectural impossibility. ONE is a
cheap self-contained nonlinear relational model with a verified useful path and
cross-panel prediction improvement,so it supports one optimization diagnosis.

R018 extended a DIFFERENT occupied-attack model at constant.01 for8epochs;loss
fluctuated and its gate failed. R013 tested.001 from random initialization on a
king-anchor model and found it worse. Neither isolates lowering the update step
AFTER an initial.01 epoch on the stronger all-piece model. The hypothesis is
that large late updates prevent a stable fit;it is not established fact. This
experiment must not become a learning-rate/epoch sweep or revive failed recipes.

Fork each immutable R028 ONE seed71/97 epoch1 state into two branches,retaining
all weights,first/second moments and global step8192. One additional full shuffled
epoch over the SAME1M CP64 examples,seed+2 order,128batch;end at16384updates.
CONTROL rate.01,LOW rate.001;no moment reset. Fix multiplicative decay to.9999
per update in BOTH branches (same shrink as parent/control),bounds.99,masked Adam
betas.9/.999,bias correction and epsilon1e-8. Holding shrink fixed isolates update
amplitude;LOW's effective decoupled decay coefficient is.1,not parent.01. State
stores rate;bound config/trainer identifies the fixed shrink rule. Do not claim
this is identical to simply passing a lower rate to the old trainer.

Correctness:prove CONTROL update byte-exact with existing updater,independently
check LOW Adam/moment/shrink equations including untouched parameters and step
continuity,verify parent bytes unchanged,exact interrupted segmented continuation
and invalid parent/config/mode/step rejection. Neural inference classes unchanged.
Checkpoint every131072 rows as in R028;resume skips verified segments,at most one
incomplete segment repeated. New unique paths,never overwrite parent states.

Four serial arms,one CPU,BelowNormal,512MiB,expected20s each,max180s/arm,no GPU or
games. Cost already measured in R028;no architecture change. Report endpoint
training/teacher/BT4 loss,full-versus-unary path utility,weights/clamp diagnostics,
resources and all identities. No best epoch/seed or additional rate selection.

Advance LOW only if BOTH seeds improve teacher MSE>=5% versus BOTH same-epoch
CONTROL and parent epoch1,with BT4 worsening<=1% versus both and full relational
loss at least1% better than unary. A pass permits a separately frozen8192/played-
position diagnosis before any playing allocation. Failure ends this recipe's
rate/epoch allocation;do not extrapolate to all optimization or neural families.
Regardless of pass,training loss is not playing strength. Data and final-validation
reservations stay unchanged. Resource gate requires preserved segment,child drain,
