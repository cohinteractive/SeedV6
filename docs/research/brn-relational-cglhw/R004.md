# R004 factorized attack-message composition

Proposed after R003's count-context table overfit. The unresolved question is
whether parameter sharing across incoming attack messages can learn useful
third-piece effects without enumerating sparse categorical contexts. This is
distinct from the historical global-softmax pair mixtures and mean-context
formulations. Admission begins with correctness and a cheap16k CPU pilot only.

Occupied pieces are graph vertices, and R003's independently checked directed
geometric attacks/defenses are edges. For each edge j→i, form an eight-dimensional
message `m_ji = E(pieceSquare_j) * R(channel_i, displacement_ji) / 2`, where `*`
is componentwise multiplication. Incoming aggregate `a_i = sum_j m_ji` and
`b_i = sum_j m_ji*m_ji`. Evaluation logit is fixed material/400 plus learned
unary terms plus `sum_i [Q(pieceSquare_i)·a_i + C(pieceSquare_i)·(a_i*a_i-b_i)]/8`.
The subtraction removes self products, so the composition term represents
distinct source pairs meeting at an occupied target. It is a learned three-piece
interaction, rather than a global affine NNUE accumulator over renamed inputs.
PAIR disables C; COMPOSE enables it. No CP64 output or backbone enters inference.

The formulation is a Codex hypothesis, not a published competitive architecture.
It deliberately excludes empty-square control and long-range positional relations;
poor results cannot reject graph methods generally. Higher-order relational utility
must beat the matched factorized pair control. Dense all-pairs variants and
incremental invalidation are deferred until an actual signal justifies their cost.

Primary research context: [Santoro et al.,2017](https://arxiv.org/abs/1706.01427)
describe shared learned pair functions followed by aggregation. Their results
are relational-reasoning tasks, not a chess engine benchmark. The proposed local
wedge composition is an inference from that design principle and R003 evidence.
[Rigaux and Kashima,2024](https://arxiv.org/html/2410.23753v1) update both edge and
node features in a chess GNN within AlphaZero-style training. Their experiments
use128-dimensional embeddings and multiple RTX A5000 GPUs; neither their search
system nor those costs establish consumer CPU alpha-beta feasibility here.

Prospective pilot: same16k/4096 consumed development split, PAIR and COMPOSE,
seeds71/97,8 epochs,batch128,Adam.01,E/R/Q independently initialized
N(0,.1),unary and C zero (matched initial PAIR/COMPOSE prediction). Check finite differences for every parameter family, graph
oracle/color symmetry, isolated-wedge dependence, finite values,tiny fit and
exact optimizer serialization/continuation. Use full-recompute cost gate10us
before updates,one logical processor,512MiB,300s/arm,per-epoch checkpoints.
This proposal is not yet an implementation or a measured result.

Advance COMPOSE only if both seeds improve endpoint development MSE by>=2%
relative to PAIR, with no cost failure. Otherwise preserve/reject this particular
composition hypothesis; do not tune repeatedly against the same panel. Compare
R003's direct EDGE diagnostically; exposure/initialization differ. No playing or
architectural-success claim from predictive loss. Reconcile R002-SCALE before
allocating another empirical workload; no concurrent training/extraction.

## Pilot result

Three new message tests passed: independent edge/message oracle and color/rank
perspective,special-position boards,distinct-source composition,finite differences
for every parameter family,tiny fit,CRC rejection and byte-exact continuation.
The earlier five research tests also passed. Runtime frozen at raw/r004-runtime.
All four runs completed; no GPU or search integration. Full inference2.03–2.80us
on the pilot panel passed the10us feasibility gate,without an incremental claim.

Endpoint MSE71/97: PAIR training.012482/.012591,validation.035229/.035877;
COMPOSE training.010207/.010162,validation.036639/.038369. This is substantial
overfit. Composition increases fit but worsens validation in both seeds; it fails
the prospective admission rule. Reject further scaling of this unregularized
composition recipe. These results do not reject all parameter-shared graph models:
a future distinct generalization hypothesis would need an explicit controlled
admission,not a continuation that ignores the failed gate. Preserve all checkpoints
and compact r004-results.json. R002's broader-data Pair-2 remains the best current
training-method candidate; no novel graph candidate is promoted.
