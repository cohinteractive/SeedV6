# R012 two-pass king-anchor neural relational network

Prospective after R011. Learned local wedge composition gained fitting capacity
but did not improve matched generalization; symbolic support is absent on38/64
remote contrasts. Test a compact global relational path without dense all-pairs
attention or conventional NNUE inference. This is one candidate,not a commitment
to a topology or a claim that CP64's remote responses should be copied.

Every occupied piece is a node; the two kings are context anchors. In STM-relative
coordinates each other piece sends an8-dimensional learned message to each king:

`a[k,d] = sum(i != k) E[pieceSquare_i,d]*R1[kingRole,displacement_ik,d] / sqrt(n-1)`.

The anchor state is `h[k,d]=softsign(a[k,d])`,where `softsign(x)=x/(1+abs(x))`.
Anchors then send learned geometry-dependent messages back to every other piece:

`z[i,d] = sum(k != i) R2[kingRole,displacement_ik,d]*h[k,d]`.

The readout is material/400 + unary/bias +
`sum(i,d) O[pieceSquare_i,d]*softsign(z[i,d])/8`.
Source and destination relation transformations are learned separately. Remote
pieces influence one another through shared anchors and nonlinear per-piece
readouts. No CP64 backbone,NNUE head or frozen BREP2 function enters inference.
This is a two-pass message computation with query-dependent outputs,not a global
affine feature accumulator followed by a conventional dense readout. Learned
relational messages must materially contribute; preserve unary-only ablation
diagnostics rather than claiming success from an unused neural relation path.

Width8,20,257 parameters:769 unary/bias;6144 source vectors;3600 first-pass
geometry vectors;3600 second-pass geometry vectors;6144 per-piece output vectors.
LINEAR disables both softsigns as a matched learned relational control; NONLINEAR
enables them. Both have global relation paths. Geometry uses225 offsets and two
relative king roles; kings send to the other king but not themselves. Piece count
normalization and material are identical. This differs from R009 direct tables:
relationships transform shared learned vectors and compose dynamically across
multiple entities. No attack graph is required; its absence is a stated design
limitation,not a hidden assumption that geometry alone is sufficient for chess.
