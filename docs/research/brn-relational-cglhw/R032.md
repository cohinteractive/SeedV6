# R032 context-dependent neural message routing

Prospective after R031 fails. R028 second-pass fixed geometry transformations
participate but do not improve over a separately trained one-pass model. R030
still shows a substantial CP64 playing gap. R031 refutes one stable-step-size
explanation without proving architecture sufficiency. Test whether a receiver
must select WHICH contextual message matters,not just sum every message through
fixed learned geometry. This is a bounded neural architectural hypothesis.

## Prior work and conceptual challenge

Historical W1-GATE and actual BrnGatedDeltaAccumulator mix four global local-pair
experts using board-level projection gates;the latter adds a frozen Gen32 base.
That is not receiver-specific routing between contextual neural piece states.
The older successor A03 disposition explicitly deferred learned attention. Its
suspended contracts/GUI gates remain untouched;this is a new isolated research
model under the current CGLHW,with no Pair/CP64 inference backbone.

[Graph Attention Networks](https://arxiv.org/abs/1710.10903) provides precedent for
learned neighborhood weighting. [Brody et al.](https://arxiv.org/abs/2105.14491)
show a query-independent ranking limitation of original GAT and motivate testing
query-dependent ranking explicitly. These graph benchmarks do not establish chess
strength or consumer Java feasibility. The following small bilinear contextual
routing is this programme's hypothesis,not a reproduction or claimed invention
of attention. Novelty relative to conventional NNUE comes from dynamic relational
computation;literature novelty is not assumed.

## Matched formulation

Keep R028's first-pass h_i,unary and Q readout. Second-pass values are h_j*S[r_ji].
Let c_i=E[v_i]+h_i and D=8. Routing score:
l_ji = B[r_ji] + sum_d K[d]*c_i[d]*c_j[d]/sqrt(D).
For each receiver i,alpha_ji=softmax over j!=i,computed by shifted exponentials.
k_i=softsign(sqrt(n-1)*sum(j!=i) alpha_ji*h_j*S[r_ji]);
readout adds sum_i V[v_i]*k_i/8. Every message depends on source neighborhood;
routing additionally depends on source AND receiving neighborhood. No global
NNUE accumulator/dense head and no frozen pair backbone. B is2700 geometry
biases,K8 learned channel couplings;65,109 parameters total. Shared old arrays
initialize exactly as R028,TWO V zero;B,K zero gives uniform initial routing.

GEOMETRY learns B only;DYNAMIC learns B and K. The GEOMETRY arm is a control,
not sufficient architectural progress. UNIFORM disables both and must reproduce
R028 TWO forward/updater exactly;reuse its existing trained endpoints. The
sqrt(n-1) factor makes uniform routing mathematically identical to R028. Preserve
rounding-order differences for active softmax initial scores as numerical,not
architectural effects. Require within1e-12 initial/control score agreement.
