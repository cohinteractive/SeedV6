# R014 globally conditioned neural attack messages

Prospective after R013. Evidence now separates two weaknesses: the local learned
wedge graph has provably missing remote support,while the global anchor model can
express those interactions but learns only a modest useful signal on broader
data. Test whether global context improves a neural computation built around
explicit chess attack/defense relations. This is a new formulation,not an extension
of failed Pair-2 training or a small NNUE correction.

Use the verified occupied-piece pseudo-attack graph (friendly targets are defenses;
sliders stop at first blocker; pins/empty-square mobility are not encoded). Share
learned8D piece-square vectors E across local and anchor messages. At each target:
`A[i,d] = sum(j -> i) E[j,d]*L[targetType,displacement,d] / sqrt(indegree_i)`.
Zero-indegree targets have A=0. Global anchor context follows R012's first pass:
`h[k,d] = softsign(sum(j != k) E[j,d]*R[kingRole,displacement,d]/sqrt(n-1))`.

For GLOBAL,form learned context-dependent gain
`K[i,d] = 1 + G[pieceType_i,0,d]*h[0,d] + G[pieceType_i,1,d]*h[1,d]`.
LOCAL fixes K=1. Both use material/400 + unary/bias +
`sum(i,d) O[pieceSquare_i,d]*softsign(A[i,d]*K[i,d])/8`.
The global path transforms local relation values before nonlinear composition.
Remote pieces influence anchor states and thereby local attack/defense readouts.
No BREP2/CP64 backbone or conventional dense NNUE head is present. This is a
context-conditioned message circuit; all source,geometry,output and gate weights
are jointly learned. Gates start0,so LOCAL/GLOBAL have identical initial scores.

Width8,38,449 allocated parameters:769 unary/bias,6144 E,21600 local geometry,
3600 anchor geometry,6144 O and192 gates. LOCAL leaves anchor/gate paths inactive;
report active versus allocated parameters and cost honestly. E/L/R/O N(0,.1),
unary/gates0. Same MSE sigmoid-logit400,Adam.01,batch128,decay.01,clamp+/-.99.
Both modes train fresh on existing1M rows for1epoch,8192 updates,seeds71/97.
Use R013's bounded flat input with batch-local graph encoding. No R010 extraction.

Correctness before training: independent local/context equations,existing graph
oracle parity,color/rank and special-board behavior,all gradient families at
nonzero gates,tiny fit,finite behavior,bounds,CRC/exact continuation,initial
LOCAL/GLOBAL equality and a disconnected remote interaction witness enabled by
global gating. Report64-case untrained response capacity without fitting teacher
deltas; missing responses remain visible. These checks do not establish chess quality.

Advance GLOBAL only if fixed endpoints beat matched LOCAL MSE>=2% in both seeds,
beat R013 LR.01 endpoints in both,and improve over their own masked relation
readout>=1%. A pass admits fresh validation before broader training or search.
Failure preserves the recipe and motivates a specific new diagnosis;no seed/epoch
selection or extension to force significance. LOCAL findings may inform later
work but cannot be called a GLOBAL success. CP64 remains the strength target.

One CPU,512MiB heap,BelowNormal,serial,max180s/arm,expected15–40s;no GPU or games.
Full inference feasibility gate10us before fitting. One epoch checkpoint; an
interruption repeats only this bounded epoch. Runtime/configs freeze after tests.
