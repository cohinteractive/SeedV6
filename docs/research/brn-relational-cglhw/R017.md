# R017 neural attack fields through occupied and empty squares

Prospective after R016. Neural CP64 supervision generalizes to fresh BRN positions,
but global conditioning contributes little and occupied-target circuits have
provably zero relational response in some sparse boards. Test a learned square
field formed by pseudo-attack/control messages,including empty destinations.
This models interactions among pieces controlling shared space as well as direct
attacks/defenses. Pinned movement legality and x-ray continuation remain absent.

Keep R014's learned8D source vectors,king-anchor context and nonlinear readout.
Targets now have13 states (12relative piece identities plus empty) and64 squares.
Messages are E[sourcePieceSquare]*L[targetState,displacement]/sqrt(indegree).
Global context K=1+sum G[targetState,kingRole]*h[kingRole] transforms these messages
before softsign and learned O[targetState,square] readout. Material/unary remain.
No CP64 or Pair-2 inference backbone. All parameters jointly learn from scratch.

OCCUPIED restricts edges/readouts to occupied targets (38449 active parameters).

predictions must match exactly. Shared tensors have identical initial bytes.
This avoids assigning an untrained initial empty-square bias to the treatment.
